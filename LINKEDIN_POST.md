🌾 **Excited to share my latest Deep Learning & Precision Agriculture Project: Rice Leaf Disease Detection System!** 🌾

Foliar crop diseases like **Bacterial Leaf Blight**, **Brown Spot**, and **Leaf Smut** pose severe threats to global food security. To help farmers and agronomists diagnose leaf diseases early, I developed an end-to-end, AI-powered web application utilizing **Transfer Learning (MobileNetV2)** that achieves **95.65% Diagnostic Accuracy**!

---

### 📌 1. Project Summary
The application processes uploaded foliage photos, resizes & normalizes images matching the exact notebook training pipeline, executes real-time model inference, visualizes confidence distributions via Plotly charts, and generates downloadable treatment reports with organic & chemical farming interventions.

---

### 🌟 2. Key Features
✔ Real-time Image Upload (JPG/PNG) & Pre-loaded Leaf Sample Selector  
✔ High-Accuracy AI Inference (MobileNetV2)  
✔ Confidence Score Meter & Plotly Probability Charts  
✔ Agricultural Reference Catalog (Symptoms, Causes, Remedies, Prevention)  
✔ Deep Learning Benchmark Dashboard (CNN vs MobileNetV2 vs VGG16 vs EfficientNetB0)  
✔ Downloadable Diagnostic Reports (.TXT)  
✔ Responsive Dark Glassmorphism UI built with Streamlit  

---

### ⚠️ 3. Engineering Challenges Faced
1. **Limited Dataset Size (120 Images):** Overcame small sample constraints using Transfer Learning with pre-trained ImageNet weights.  
2. **Preventing Overfitting:** Implemented Dropout layers (0.4 rate), Batch Normalization, and EarlyStopping callbacks.  
3. **Selecting Best Architecture:** Benchmarked 4 DL models; MobileNetV2 achieved 95.65% accuracy compared to VGG16 (82.61%), CNN (34.78%), and EfficientNetB0 (30.43%).  
4. **Preprocessing Normalization:** Maintained strict RGB color space and 1/255 float32 scaling across training, validation, and web inference.  
5. **Improving Model Generalization:** Applied ImageDataGenerator augmentation (rotation, shift, zoom, horizontal flip).  
6. **Saving & Deploying Model:** Exported model in native `.keras` format and deployed on Streamlit Cloud with cached inference.
